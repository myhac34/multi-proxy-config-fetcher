# Multi Proxy Config Fetcher

جمع‌آوری، تست و دسته‌بندی خودکار کانفیگ‌های V2Ray.

## امکانات

- دریافت کانفیگ از چند منبع
- حذف کانفیگ‌های تکراری
- تشخیص کشور سرور
- تست کانفیگ‌ها با Xray و Sing-box
- دسته‌بندی کانفیگ‌ها بر اساس منطقه
- به‌روزرسانی خودکار با GitHub Actions

## دسته‌بندی‌ها

کانفیگ‌ها در این مناطق قرار می‌گیرند:

- آمریکا و کانادا
- اروپای غربی
- اسکاندیناوی
- روسیه و کشورهای CIS
- چین و شرق آسیا
- خاورمیانه
- اروپای شرقی
- آفریقا
- سایر کشورها

## لینک اشتراک‌ها

پس از اجرای GitHub Actions، فایل‌های اشتراک در این مسیر ساخته می‌شوند:

`configs/regional/`

هر فایل را می‌توان به‌عنوان Subscription در Throne یا کلاینت‌های سازگار استفاده کرد.

## به‌روزرسانی

GitHub Actions به‌صورت خودکار کانفیگ‌ها را به‌روزرسانی می‌کند.

برای اجرای دستی:

`Actions → Update Proxy Configs → Run workflow`
